1.0 User Persona & Top 5 Support Bottlenecks

Target: Non-Technical SMBs

The Target User: Non-technical business owners, boutique D2C founders, and offline retail marketing managers (e.g. jewellery brands on IndiaMART, boutique hotels on FabHotels). They excel at commerce and customer sales, but Meta developer permissions, WhatsApp Business API (WABA) verification, and JSON payload errors cause severe onboarding anxiety.

Support Bottleneck Technical Failure Mode & Root Cause Strategic Prioritization Rationale
1. Meta Template Rejections
Cloud API 132015		 Merchant selects Utility rate (₹0.12), but includes promotional discount text or lacks required fallback parameter mapping ({{1}}). 35% of all support tickets. Blocks merchants right at the high-intent campaign launch phase.
2. WABA Phone Number Binding
Cloud API 133010		 Phone number is already locked to standard consumer WhatsApp or 2FA PIN is unreleased in Meta Business Manager. #1 Blocker to First Value. Triggers immediate merchant churn within first 48 hours of signup.
3. CSV Audience Upload Errors
CSV Dial Code Missing		 Broadcast lists fail upload due to missing country code (+91 missing on domestic mobile numbers), special characters, or trailing spaces. High-frequency repetitive ticket before every broadcast blast; 100% deterministic to validate.
4. Bot Trigger & Loop Traps
Fallback Recursion		 Conflicting keyword triggers or dead-end conversation paths causing infinite automated default fallback loops. Directly ruins the merchant's end-customer brand reputation, causing high-anxiety emergency escalations.
5. Integration & Webhook Drops
OAuth Token Expiry		 Shopify or WooCommerce abandoned cart events disconnect after secret rotation or permissions changes. Silently causes lost revenue for the merchant; creates high perceived platform instability.

2.0 Chosen Solution: "Cheerio Co-Pilot" System Architecture

In-App Diagnostic Agent

Product Vision: Cheerio Co-Pilot is an embedded, state-aware copilot living natively in the merchant workflow. Rather than forcing the merchant to draft a support ticket, Co-Pilot automatically parses third-party API error responses, explains the issue in plain conversational language, and provides a single-click remediation button.

Co-Pilot Module Operational Mechanism & Autonomous Action Impact on Support Deflection
Pre-Flight Template Linter Real-time syntax & policy validator running on draft templates. Detects promotional wording in utility categories, suggests 1-click compliant rewrites, and maps fallback variables before calling Meta API. Eliminates 94% of template rejection tickets before submission occurs.
1-Click CSV Sanitizer Validates uploaded CSV contact files on the client side. Automatically formats numbers to E.164 standard (+91 prefix), deduplicates records, and cleans invalid characters. Converts 20-minute manual support formatting inquiries into an instant 1-click operation.
Bot Flow Loop Simulator Synthetically runs test trajectories through drag-and-drop chatbot trees to detect orphaned branches, recursive fallback loops, or broken triggers before activation. Prevents live customer-facing dead ends that create high-urgency merchant panic tickets.
Integration Self-Healer Continuously monitors webhook health with Shopify/WooCommerce. Detects auth token expirations and provides a 1-click OAuth reconnection prompt. Eliminates silent data drops and restores automated order alerts autonomously.

2.1 Operational Boundaries: What the Co-Pilot Will NOT Do

Strict Guardrails
  • No Financial Transactions or Billing Disputes: The Co-Pilot strictly refuses to handle credit card disputes, refund calculations, or plan cancellations. These are immediately routed to human billing specialists.
  • No Hallucinated Compliance Overrides: If Meta permanently disables an account for severe spam violations, Co-Pilot does not make false promises; it automatically compiles an official Meta Policy Appeal Dossier for human review.
  • Zero Infinite Bot Loops (2-Attempt Circuit Breaker): If an automated remediation fails 2 consecutive times, Co-Pilot halts automated retries and executes a warm hand-off to human support.

2.2 Human Hand-Off Protocol: "Diagnostic Ticket Packets"

When human intervention is mandatory, the merchant is never forced to repeat themselves. Co-Pilot automatically dispatches a structured Diagnostic Telemetry Packet directly into the support agent's Zendesk/Slack queue containing:

  • Diagnostic Telemetry: Exact Meta Cloud API error code, raw JSON payload, Account ID, WABA status, and timestamp.
  • History: Actions already attempted by merchant and specific failure trigger.
  • Recommended Human Remediation: Exact steps for agent (e.g. "Advise user to navigate to WhatsApp Settings > Account > Delete Account to release 2FA lock"). Cuts Mean Time to Resolution (MTTR) by 70%.

4.2 Prompts That Failed & Iterative Refinements

Failed Initial Attempt Generic Support Automation "How can Cheerio AI use AI to reduce customer support tickets?"

Iterative Refinement: Switched to a persona-anchored, state-aware prompt defining Cheerio's user as a non-technical SMB merchant in India facing WhatsApp API verification drops, and mandated programmatic in-app auto-remediation rather than passive text.
