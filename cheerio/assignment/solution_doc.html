Executive Summary: Cheerio supports 5,000 active Indian SMB merchants generating ~17,500 support queries/month. The core problem is not an FAQ deficiency; it is technical onboarding friction across Meta Cloud API compliance, phone binding, and CSV formatting. Instead of a conversational chatbot that requires users to explain technical errors, we designed Cheerio Co-Pilot: an embedded, state-aware widget providing 1-click deterministic remediations. This strategy reduces support cost per ticket by 62.4% (from ₹40.00 to ₹15.06), avoids 13 support hires as volume scales, generates ₹52.38L in net annual operational savings, and delivers a 50.4x net ROI on monthly AI spend by curbing merchant churn.
1.1 The Core Scaling Bottleneck for Non-Technical Merchants

Cheerio empowers non-technical business owners (retail jewellers, D2C brands, clinics, coaching centers) to run WhatsApp marketing campaigns. However, these users struggle with strict developer platforms: Meta Business Manager, Cloud API error payloads, 2FA coexistence traps, and strict CSV schemas. When a template is rejected or a phone number fails to bind, merchants cannot diagnose the technical root cause. They submit repetitive, high-touch support tickets ("WhatsApp is broken", "My blast won't send"), overwhelming Cheerio's human support operations.

2.1 Product Specification: The In-App Context-Aware Co-Pilot

Cheerio Co-Pilot is embedded directly into campaign workflows (WhatsApp Templates, CSV Audiences, Phone Registration). Unlike conversational chatbots that live in a detached widget, Co-Pilot maintains real-time DOM telemetry: form field values, draft history, account verification status, and Meta Cloud API HTTP response headers. When a merchant makes an error, Co-Pilot provides two transparent, 1-click remediation paths on-screen:

Path A: Clean Utility (1-Click Auto-Fix) Meta Rate: ₹0.1150/msg

Strips violating promotional phrases (e.g., "HURRY! 50% OFF Diwali Sale") while preserving dynamic variables ({{1}}). Rewrites message into strict transactional compliance with live phone diff preview, 1-click rollback, and disclaimer that final approval rests with Meta.

Path B: Reclassify to Marketing Meta Rate: ₹0.8631/msg

Preserves the merchant's promotional discount copy, automatically reassigns the template category to Marketing, and alerts the merchant to the higher Meta delivery tariff (₹0.8631 vs. ₹0.1150 base rate), preventing surprise billing disputes.

2.2 Multi-Tier Resolution Engine & Cost-Optimized Pipeline

To deliver fast user responsiveness and keep raw LLM inference costs below ₹0.20 per query (blended fully loaded cost is ₹1.20/query including vector search, hosting, Redis cache, and monthly tooling), Co-Pilot utilizes a 3-tier processing pipeline:

Tier 1: Client Regex Linter Local • Free

Deterministic browser checks evaluate variable counts, whitespace, and promo keywords. Traps 100% of missing country codes on CSV uploads without making an LLM API call.

Tier 2: Semantic Vector Cache Edge • Low Cost

An Upstash Redis semantic cache matches inbound copy against verified compliant template patterns. Returns instant cached rephrasings for standard Indian festive campaigns.

Tier 3: GPT-4o-mini LLM Cloud API • ₹0.18

Invoked only for novel, complex copy rephrasing or Hinglish intent parsing. Uses structured JSON outputs with prompt caching (50% input discount) to deliver exact replacement payloads.

2.4 2-Failure Escalation Circuit & Structured Diagnostic Telemetry Packet

If a merchant struggles or the automated fix fails twice consecutively, Co-Pilot trips a deterministic circuit breaker. Instead of trapping the user in an infinite bot loop, Co-Pilot compiles a structured JSON Diagnostic Packet directly to the human support queue:

2.5 Operational Guardrails & Explicit Refusal Boundaries
Financial & Invoicing Disputes Hard Refusal

Policy: Co-Pilot is strictly prohibited from executing financial adjustments or issuing refund guarantees. Any query regarding credit card overcharges, failed renewals, or invoice adjustments routes instantly to the Human Finance Desk with account billing telemetry.

Meta Ban & License Boundaries Zero-Override

Policy: Cheerio cannot arbitrarily override Meta's compliance servers. When accounts are flagged for spam, Co-Pilot refuses to promise an unban. It generates the official appeal dossier and assigns it directly to Cheerio's Meta Compliance Lead.

3.2 Strict Deflection Definition & Customer Quality Guardrails

Audit-Proof Deflection Standard: A support interaction is counted as "Deflected" only if the merchant completes their workflow in-app and raises no human ticket or reopened inquiry within 7 calendar days. Users who abandon the workflow in frustration are explicitly categorized as "Failed Deflections" to prevent false reporting.

Guardrail 1: Post-Remediation CSAT Target: ≥ 4.5 / 5.0

1-click rating displayed immediately after auto-fix. If a specific linter rule falls below 4.0 CSAT, it is demoted to "Human Review Only" automatically.

Guardrail 2: Escalation Telemetry Target: ≥ 95%

Monitors percentage of human-escalated tickets containing a valid Diagnostic Packet. Ensures support reps never ask merchants for account ID or screenshots.

6.1 AI Collaboration & Engineering Retrospective (Part 3)

AI Tools Used: Claude 3.5 Sonnet / Antigravity Agent (architecture, Meta API error taxonomy, financial modeling); Cursor & Tailwind CSS (interactive prototype development); ChatGPT-4o (support benchmark validation).

3 Key Prompts That Worked:
1. Meta Error Taxonomy: "Break down top failure codes for WhatsApp templates on Meta Cloud API (INCORRECT_CATEGORY, 133010, 132015) with programmatic actions."
2. Financial Token Economics: "Calculate token costs for 17,500 queries on GPT-4o-mini ($0.15 in, $0.60 out, $0.075 cache) vs. 40 tickets/day Indian support salary (₹35k/mo)."
3. Prototype Architecture: "Create interactive Material 3 UI with 4 scenarios: pre-flight linter, 2-failure circuit breaker, refusal guardrail, and phone binding 133010."

Failed Prompt & Iteration: Initial query asked to "calculate ROI replacing support agents". AI assumed 100 tickets/day (2.5x industry capacity) and divided gross revenue by cost. Corrected prompt to 40 tickets/day, 22 workdays (880 tickets/mo), avoided hiring framing, and explicit gross/net ROI separation.

AI Hallucination Caught: AI suggested overriding Meta's backend approval status. Caught: Cheerio as an official BSP cannot override Meta compliance servers. Corrected to a client-side pre-flight linter that rephrases copy before API submission.

Candidate Plain-Voice Reflection: "I chose Assignment A because onboarding support friction directly caps merchant activation—if an SMB's first WhatsApp broadcast is rejected by Meta, they churn before month two. I initially doubted whether non-technical shop owners would trust an automated AI rewrite over a human agent, which is why I designed 1-click diff previews with explicit tariff warnings rather than silent background auto-fixes. The biggest decision I changed my mind on was pricing: I initially considered a per-resolution fee, but modeling the economics showed that retaining even 1.2% more merchants via free self-serve fixes yields ₹1.61L/month in net preserved MRR—making a free core copilot far more valuable to Cheerio's bottom line than charging users for support."
